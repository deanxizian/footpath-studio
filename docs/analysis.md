# 分析口径

## 原始坐标

每个 Footpath 片段包含左/右脚、时间戳和按采样顺序排列的 XYZ 点。页面保留片段边界和原始数值，Z 轴朝上、三轴等比例。镜像只翻转左脚 Y 轴。

X、Y、Z 幅度是该片段在对应坐标轴上的最大值减最小值。未经独立标定，原始单位不解释为人体步幅、步宽或身体垂直振幅。

## 跨次比较

- 固定速度筛选使用同一目标速度的 ±5%，每次跑步与基准都使用相同条件。
- 每侧、每项指标使用符合筛选的片段中位数；至少 3 段有效值才计算相对变化。
- 变化率为 `(当前中位数 − 基准中位数) / 基准中位数 × 100%`。基准为零或样本不足时显示缺失，不显示 0%。
- 三维图分别选取最接近该侧 X/Y/Z 幅度中位数的真实片段。CSV 提供从 0 开始的原始片段索引，便于复核；它不是平均曲线。
- 长期图一点评估一次跑步，粗线是最近 5 次有效跑步的滚动中位数。日期筛选按上海时区、以最后一次记录为终点。
- 单次分析按经过时间划分前三分之一、中三分之一、后三分之一和固定分钟窗口，不按筛选后剩余片段重新分配时间。

三维细节中的异侧配对选择时间差不超过 1.5 秒的最近片段。周期播放按点序展示，每只脚独立映射到 0–100%，不是同步重建人体运动。

鞋、路面、坡度、速度和传感器佩戴方式可能影响结果。页面用于观察趋势，不将幅度变大或变小直接判定为跑姿改善。
