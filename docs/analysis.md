# 分析口径

## 个人基准

- 默认选择最近一次跑步，基准默认为最近 90 天。顶部全局选择器支持 30、60、90、180、365 天；基准范围为 `[最新一次运动开始时间 − 所选天数 × 24 小时, 最新一次运动开始时间]`，包含两端。所选跑步在范围内时也参与平均，不因被选中而排除。
- 三维基准轨迹、各指标基准、左右差异基准、趋势图和变化摘要共用顶部所选天数及最新一次跑步的截止时间。切换历史跑步只改变当前对比对象，基准范围、记录集合、均值及趋势均保持不变。切换天数不改变当前跑步或公里范围。
- 优先使用活动开始时间。开始时间晚于首个 Footpath 片段时使用首个片段时间，避免出现负的经过时间。日期展示使用上海时区。
- 不筛选速度、路面或跑鞋。
- 每次跑步先对每只脚、每项指标清理并求均值，再对各次跑步的有效均值等权平均。片段多或时长长的跑步不会获得更大权重。不因某一指标异常而删除整条记录。
- 基准按指标独立统计有效跑步数；缺失值和不足样本不参与平均。基准为零时不计算相对变化；没有基准时保留本次值，变化显示为空。

## 极端离群值与缺失值

每侧、每项指标使用整次跑步的有效片段计算四分位数。至少 8 个值且四分位距（IQR）大于零时，剔除低于 `Q1 − 3 × IQR` 或高于 `Q3 + 3 × IQR` 的值，然后计算算术平均值。四分位数使用排序后的线性插值。

样本少于 8 个或 IQR 为零时不自动剔除；清理后不足 3 个有效值时不展示均值。坐标幅度允许零，时长指标要求大于零。缺失、非有限值不补成零。

本次与基准的变化为 `(当前均值 / 基准均值 − 1) × 100%`。页面只展示结果，样本数放在基准数值的悬停提示中；每个片段的不同指标独立判断。

## 左右脚差异

- 当前差值：`右脚均值 − 左脚均值`，保留指标单位。
- 当前相对差异：`(右脚均值 − 左脚均值) / ((右脚均值 + 左脚均值) / 2) × 100%`。
- 正值表示右侧更高，负值表示左侧更高；任一脚缺失或两脚均值为零时不计算相对差异。
- 基准差异为各次跑步相对差异的等权平均，仅包含左右脚都有效的跑步。因此，它与“先汇总各脚均值，再计算差异”不一定相同。
- 趋势图保留差异的方向；趋势摘要中的“左右差异大小”对每次差异先取绝对值再平均，避免某些天左高、另一些天右高互相抵消。
- 左右脚是同次或同阶段的汇总比较，不宣称逐步一一配对。

## 单次跑步的公里范围

- 默认显示全程，只提供两个可手动拖动的端点，分别选择起止公里，没有固定分段长度或模式切换。切换跑步时恢复全程。
- 当前归档没有逐片段累计距离。按 Footpath 速度沿真实经过时间积分，再用活动总里程校准；同一时刻的左右脚速度先平均，避免重复累计。相邻速度点线性插值，记录开始前、结束后的范围沿用最近速度。底层时间从运动开始到最后一个已有 Footpath 片段，不把 moving time 当作包含暂停的经过时间。
- 公里位置以“≈”标注估算；暂停、记录缺口或首尾未完整记录会影响定位精度，不能视为精确的实际公里点。活动总里程缺失时使用速度积分总量；无有效速度或时长时只显示整次跑步。
- 所选范围沿用整次跑步的离群判定边界，包含起点、不包含终点，终点为全程末端时包含最后一个片段。拖动只改变当前轨迹与指标，不重新定义基准或历史趋势。
- 缺录区间显示空，不生成额外 Footpath 样本。配速图每分钟汇总实际记录速度并换算为 min/km，再映射到估算公里位置；无数据的分钟断开。

## 多次跑步的趋势

- 趋势与顶部共用 30、60、90、180、365 天范围，始终以归档中最近一次跑步的开始时间为终点，包含范围起点及最近一次跑步。切换所选活动不改变趋势范围、数据点或摘要。横轴完整覆盖所选天数，记录不足的首尾保留空白。趋势板块不再提供独立的时间选择器。
- 每个点是一场跑步清理后的均值，单位为原始指标单位，不使用不断变化的基准百分比串成趋势。
- 数据点默认使用相同的小圆点，不持续突出当前所选活动；悬停时两张图按同一条记录同步高亮并显示数值，移开后恢复。点击点仍可切换上方的活动对比，趋势时间范围保持不变。
- 线为当前显示范围内最近 5 次有效跑步的算术平均；不足 5 次不画趋势线，当前记录缺失时不连线。
- 摘要表示所选范围内从期初到期末的变化，直接复用图表的记录，不读取前一个周期。先保留至少一脚有当前指标的跑步；期初与期末各取 `min(5, floor(有效跑步数 / 2))` 次，两个集合不重叠，左右脚使用相同的跑步集合。
- 各脚在两端分别求有效跑步的等权均值，每端至少 3 次有效记录才显示变化；一脚不足不会影响另一脚。左右差异大小仅使用两脚都有效的记录，先取每次相对差异的绝对值再求均值，直接显示期初与期末的百分比。摘要用于概括起止变化，中间波动仍由趋势图展示。
- 摘要不随单次跑步的公里范围变化。“差异增大/差异减小”描述左右差异绝对值的变化，两端相差不足 0.05 个百分点时显示“基本持平”，不判断健康、受伤或跑姿改善。

## 原始坐标

X、Y、Z 幅度是一个原始片段在对应坐标轴上的最大值减最小值。未经独立标定，保留原始单位，不解释为人体步幅、步宽或身体垂直振幅。完整轨迹保存在原有月度归档中。

## 三维平均轨迹

- 每只脚分别处理。沿用片段的原始起点，减去起点坐标偏移，将原始采样序列的相对进度线性插值到 101 个点；不按长度或高度缩放。
- 使用整次跑步的 XYZ 幅度离群边界，任一坐标幅度越界的片段不参与三维均值；时长缺失不影响三维轨迹。至少 3 个有效片段才显示本次或当前阶段的均值。轨迹需要完整形状，使用的片段集合可能与逐指标独立清理的表格略有不同。
- 每次跑步先对各片段对应进度的坐标求平均；历史基准再对各次跑步平均轨迹等权平均，范围与指标基准相同。左右脚有效基准数显示在虚线图例的悬停提示中。
- 实线是所选跑步或公里范围的平均轨迹；虚线是所选历史范围的基准，拖动公里范围条时保持固定。橙色为左脚、蓝色为右脚。镜像只影响显示坐标，不改变指标或存储数据。
- 三维显示沿用 Stryd 可视化的坐标转换 `(X, -Y, Z)`，轴刻度采用显示坐标；各轴幅度、统计指标与归档数据仍按原始坐标计算。后方视角从负 X 方向朝正 X 观察，默认 3D 从右后方以水平 45° 方向观察，平分 X、Y 轴夹角。
- 这是本项目的平均形状算法，不宣称与 Stryd 官方的处理算法一致。相对采样进度不表示绝对步态时长；触地和周期时间继续独立分析。
- 构建时生成逐次平均轨迹摘要，作为网站 assets 文件；本地开发和构建缓存按算法版本及数据签名复用。原始 Release 文件不变，浏览器只下载当前跑步的完整轨迹和平均摘要。
