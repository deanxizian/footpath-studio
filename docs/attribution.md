# 依赖与参考

软件源码采用 MIT 许可证。第三方依赖保留各自许可证：

- [React](https://github.com/facebook/react)：MIT，界面与状态管理。
- [Three.js](https://github.com/mrdoob/three.js)：MIT，三维轨迹渲染及 OrbitControls。
- [Recharts](https://github.com/recharts/recharts)：MIT，趋势图。
- [Vite](https://github.com/vitejs/vite)：MIT，本地开发与构建。

界面交互参考 [Stryd 的 3D Footpath 介绍](https://blog.stryd.com/2024/01/16/3d-stryd-footpath/)，实现、样式和演示曲线由本项目独立编写。Stryd 为其权利人的品牌，本项目不代表 Stryd，也不提供订阅或账号访问能力。

`src/demo.js` 数据由确定性数学公式生成，不取自任何人的运动记录。维护者个人历史快照经本人授权单独公开；源码的 MIT 许可证不代表对其他人数据的授权。
